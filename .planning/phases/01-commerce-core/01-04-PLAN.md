## Phase Goal

**As a** customer, **I want to** browse what is available this round and ask to be alerted when a sold-out item returns, **so that** I only try to buy what is really in stock.

<objective>
Expose the public, no-auth catalog that Phase 2 LIFF will consume: varieties + sale units with live per-round availability, resolved tiered prices, the "หมดรอบนี้" sold-out label, and the multi-mode (pre-order / ready-to-ship) surface — plus a data-only back-in-stock request endpoint. This is criterion 5's customer-facing sold-out/alert behavior and SALE-04's multi-mode surface.

Purpose: INV-08 (sold-out label + back-in-stock request), SALE-04 (multi-mode product surface), SALE-01/02 (pre-order vs ready-to-ship derived from round timing).
Output: `routes/catalog.ts` (public reads) + `routes/stock.ts` (back-in-stock records), wired in `index.ts`, with catalog + sold-out tests.
</objective>
