<objective>
## Slice user story
**As a** ลูกค้า B2B (และแอดมินผู้อนุมัติ), **I want to** สมัคร/อนุมัติบัญชี B2B เพื่อเห็นราคาส่ง และตั้งออเดอร์ประจำที่กันโควตาจากผลผลิตคาดการณ์ก่อนเปิดขาย B2C, **so that** ลูกค้าส่งรายใหญ่ได้ของแน่นอน ไม่แย่งสต็อกกับ B2C.

Vertical slice: web-admin (B2BApprovals, StandingOrders) → API (b2b.ts: approval + wholesale gate + standing reserve + overflow) → DB (customers.b2b_status/credit_terms, standing_orders/items, quota_overflow_flags). ครอบ Success Criterion 3 ส่วน B2B (CUST-02/05).

Purpose: "reserved before B2C" = orchestration ผ่าน reserve() เดิม (Pattern 2) — ไม่สร้าง oversell regression.
Output: B2B approval + standing order + overflow flag end-to-end. (หน้า LIFF ลูกค้า B2B อยู่ 03-08.)
</objective>
