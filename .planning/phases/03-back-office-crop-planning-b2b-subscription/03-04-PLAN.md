<objective>
## Slice user story
**As a** ผู้ดูแลแปลง (grower), **I want to** ตั้งค่าพันธุ์ผัก + บันทึกรุ่นปลูก + กดสร้างแบตช์จากสูตรปลูกในวันจันทร์, **so that** ระบบคำนวณวันเก็บคาด/ผลผลิตคาดให้อัตโนมัติ ตรงกับรอบการปลูกจริง (จันทร์ปลูก ~200 ต้น 6 ชนิด).

Vertical slice: web-admin (VarietyParams/PlantingBatches/PlantingMix) → API (crop.ts routes, grower-gated) → DB (varieties params, planting_batches, planting_mix_templates/items). รวม forecast pure service (compute เท่านั้น — publish อยู่ 03-05).

Purpose: ครอบ Success Criterion 1 ส่วน "ตั้งค่าพันธุ์ + planting mix → auto-create batches → projects expected yield" (CROP-01/02/03/06).
Output: crop CRUD end-to-end + forecast pure fns.
</objective>
