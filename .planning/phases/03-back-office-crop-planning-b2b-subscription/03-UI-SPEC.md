# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Two surfaces this phase:**
> 1. **`web-admin/` — NEW desktop staff back-office** (Vue 3.5 + Vite + Tailwind v4 + TanStack Query/Table, `jose` session auth — CONTEXT D-17/18). Dashboard, crop planning, packing queue, reports, settings, RBAC, B2B approval, subscription/standing admin. Data-dense, mouse-first, sidebar-nav layout. This is the bulk of the new design work.
> 2. **`web/` LIFF — mobile customer additions** (extends the **approved [02-UI-SPEC](../02-line-storefront-payments-delivery/02-UI-SPEC.md)** verbatim): B2B wholesale-price visibility, subscription package pick + pause/skip/cancel, substitution notice. These inherit the Phase-2 mobile contract exactly — no new token language.
> 3. The **canned LINE chatbot** (D-25) renders as Flex cards inside the LINE client, not the DOM. Its copy is contracted here (§Copywriting → Chatbot); pixel layout is Claude's-discretion (CONTEXT).
>
> All copy is **Thai** (NFR-07). Staff tone = operational, clear, verb-first. Customer tone = friendly farm-fresh (matches Phase 2).

## Spacing Scale

8-point scale, all multiples of 4 — identical tokens to Phase 2:

| Token | Value | Usage (desktop back-office) |
|-------|-------|-----------------------------|
| xs | 4px | Icon-to-label gaps, badge inset, chip padding |
| sm | 8px | Data-table cell **vertical** padding, compact form-row gaps, dense list rows |
| md | 16px | Default: card padding, table cell **horizontal** padding, gap between form fields, toolbar padding |
| lg | 24px | Section padding, gap between dashboard cards, page content inset |
| xl | 32px | Major block breaks, page header → content gap |
| 2xl | 48px | Empty-state vertical centering, top-of-report rhythm |
| 3xl | 64px | Full-page state (first-run / no-data) vertical rhythm |

**Exceptions & desktop layout constants (achieve via padding — never break the 4px grid):**
- **Sidebar nav width:** 240px (collapsed rail: 64px).
- **Data-table row min-height:** 40px; header row 40px. Zebra/hover surface = Secondary `#F1F5EC`.
- **Interactive control min-height:** 32px (mouse target); **primary buttons 40px**; row-action icon buttons 32×32px hit area.
- **Form content max-width:** 640px (single-column readable forms); full-bleed for tables/reports.
- **Modal/confirmation dialog width:** 480px default, 640px for multi-field (e.g. log-harvest, edit-mix).

## Typography

Exactly **4 sizes, 2 weights**. Line-heights sit slightly above Latin norms — Thai stacks vowel/tone marks and needs vertical room. Consistent with Phase 2, tuned for desktop data density.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Display (dashboard KPI number, report headline figure, page total) | 28px | 600 semibold | 1.3 |
| Heading (page title, card/section title, modal title, chart title) | 20px | 600 semibold | 1.35 |
| Body (form field values, card body, description, primary reading text) | 16px | 400 regular | 1.6 |
| Label (table cells, table headers [600], nav items, badges, captions, helper/error text, filter chips) | 14px | 400 regular (600 for table headers + active nav item + emphasized metric label) | 1.5 |

Rules:
- **Never below 14px** — table cells and captions bottom out at Label size for readable Thai.
- **Numeric alignment:** money and quantity columns in tables render **right-aligned, tabular** (`font-variant-numeric: tabular-nums`); the `฿` symbol at the same size as the figure (e.g. `฿1,240`).
- Only two weights ship (400, 600). No light/thin/bold-800.

## Color

Same fresh-salad 60/30/10 brand as Phase 2 — desktop chrome (sidebar/toolbar) uses the Secondary surface so the palette stays inside budget.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` | Page/content background, table body, form background, card fill |
| Secondary (30%) | `#F1F5EC` | Sidebar nav, top toolbar, table header row, row hover/zebra, KPI card surface, section dividers |
| Accent (10%) | `#2E7D32` | See reserved list below (contrast 4.6:1 on white — WCAG AA; button text on accent is `#FFFFFF`) |
| Destructive | `#D32F2F` | Destructive/failure only (see reserved list) |

**Supporting neutrals (text/border ink — outside the 60/30/10 budget, same as Phase 2):**
- Text primary `#1B2A1B` · Text muted `#5B6B5B` · Border/hairline `#E2E8DD`.

**Accent (`#2E7D32`) is reserved for — explicit list, never "all interactive elements":**
1. The **one primary action button per view** (e.g. `เผยแพร่จำนวนขาย`, `บันทึกการเก็บเกี่ยว`, `สร้างแบตช์`, `อนุมัติ`, `บันทึก`, `ส่งออก CSV`).
2. The **active sidebar nav item** (fill/left-rail indicator) and the active tab underline.
3. The **selected-row** left indicator and selected filter-chip fill in a data table.
4. **Positive status** badge/dot (`ชำระแล้ว` paid · `เผยแพร่แล้ว` published · `อนุมัติแล้ว` approved · `มีของ` in-stock).
5. The **primary/first series** in a chart, and the "this round / positive delta" mark.

Everything else interactive (secondary buttons, `แก้ไข`/`ดู` row links, pagination, sort carets, breadcrumb) uses **neutral ink + border, not accent** — keeping one unambiguous primary action per view.

**Destructive (`#D32F2F`) is reserved for:** delete-batch / delete-mix-template / cancel-round, reject-B2B-account, admin cancel-order / reject-slip, cancel-subscription (admin), the **B2B quota-overflow flag** severity (D-10), `ยังไม่ชำระ`/`ปฏิเสธ`/`ขายหมด`/`เกินโควตา` negative status, and inline form validation errors.

### Status badge palette (supporting — outside 60/30/10; drives the data-dense state set)

| Semantic | Text | Surface | Applied to |
|----------|------|---------|-----------|
| Positive | `#2E7D32` | `#F1F5EC` | paid · published · approved · in-stock · harvest ≥ forecast |
| Warning | `#B26A00` | `#FFF4E5` | near-sold-out · unpaid (awaiting) · slip awaiting-review · **B2B overflow flag** · forecast > actual delta · draft-pending-publish |
| Negative | `#D32F2F` | `#FDECEA` | rejected · cancelled · sold-out · over-quota · payment-expired |
| Neutral | `#5B6B5B` | `#F1F5EC` | draft · pending · scheduled · paused (subscription) · skipped |

Status colors are for **badges/dots/inline text only — never button fills** (accent/destructive own the actions).

### Chart categorical palette (D-24 reports — series by channel / product / round)

Ordered, distinguishable, brand-anchored. Series 1 is the leaf-green accent (primary metric / B2C):

| # | Hex | Suggested fixed mapping |
|---|-----|--------------------------|
| 1 | `#2E7D32` | B2C / primary metric |
| 2 | `#1565C0` | B2B |
| 3 | `#B26A00` | Subscription |
| 4 | `#6A1B9A` | 4th category (product/variety) |
| 5 | `#00838F` | 5th category |
| 6 | `#C2185B` | 6th category |

Keep channel↔color mapping **stable across every chart** (B2C always green, B2B always blue, Subscription always amber) so the reader learns it once. Cap simultaneous series at 6; roll the remainder into an "อื่น ๆ" bucket at a neutral grey `#9AA69A`.
