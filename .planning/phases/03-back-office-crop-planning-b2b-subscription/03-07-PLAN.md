## Slice user story
**As a** สมาชิกกล่องผัก (subscriber) และแอดมิน, **I want to** ให้ระบบสร้างออเดอร์กล่องผักอัตโนมัติทุกรอบและกันสต็อกให้ก่อน B2C พร้อมหยุด/ข้าม/ยกเลิกได้ และแจ้งเมื่อมีการปรับผักในกล่อง, **so that** สมาชิกได้กล่องผักสดทุกรอบไม่มีวันหมด และจ่ายต่อรอบด้วย flow เดิม.

Vertical slice (backend + web-admin admin): API (subscription.ts fill service, subscriptions.ts routes, boss.ts generator) → DB (subscriptions/skips/subscription_orders). ครอบ Success Criterion 3 ส่วน subscription (SALE-03). หน้า LIFF ลูกค้า (สมัคร/จัดการ) อยู่ 03-08.

Purpose: generator ตัวแรกของระบบ — reuse pg-boss + reserveBox() + payment เดิม; idempotent.
Output: subscription generate + reserve + pause/skip/cancel + substitution notice + admin view.
</objective>
