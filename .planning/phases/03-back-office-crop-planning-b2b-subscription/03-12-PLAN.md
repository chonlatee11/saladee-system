## Slice user story
**As a** เจ้าของ/แอดมิน (และลูกค้าใน LINE), **I want to** ปรับค่าระบบที่เปลี่ยนบ่อยจากหลังบ้านโดยไม่ต้อง redeploy และให้ลูกค้าถามเมนู/ราคา/ของเหลือผ่านแชทบอทที่ลิงก์เข้า LIFF ได้, **so that** ดูแลร้านคล่องขึ้นและลูกค้าเข้าถึงข้อมูล/สั่งซื้อง่ายขึ้น.

Vertical slice: web-admin (Settings) → API (settings.ts hot config, staff-gated) → DB (settings table); + chatbot canned extension บน webhook.ts (backend + LINE Flex). ครอบ Success Criterion 5 ส่วน settings (ADM-03) + chatbot (MKT-02).

Output: settings + chatbot end-to-end.
</objective>
