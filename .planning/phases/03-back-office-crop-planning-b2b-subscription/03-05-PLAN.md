## Slice user story
**As a** แอดมิน, **I want to** ตรวจ draft จำนวนขายที่ระบบคำนวณจากปฏิทินเก็บเกี่ยวแล้วกด "เผยแพร่" ก่อนรอบเปิด (พร้อมแก้เองได้และคงค่าไว้ถาวร) และบันทึกผลเก็บเกี่ยวจริงพร้อม lot/best-before, **so that** จำนวนที่เปิดขายตรงกับผลผลิตจริง (แทนกรอกมือ) และมี traceability.

Vertical slice: web-admin (HarvestCalendar publish/override, HarvestLog) → API (harvest.ts: publish + override + log) → DB (round_stock.quota_plants + is_manual_override, harvest_logs). ครอบ Success Criterion 2 (CROP-04/05, INV-10) + admin publish gate (CROP-03 mapping D-07).

Purpose: แทนที่การกรอกจำนวนขายมือของ Phase 1 ด้วย crop auto-feed (กด publish) + คง manual override ถาวร.
Output: publish/override/harvest-log end-to-end.
</objective>
