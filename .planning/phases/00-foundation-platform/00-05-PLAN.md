## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → /auth/staff | Untrusted credentials; constant-time hash verify, no user enumeration in errors |
| LIFF client → /auth/line | Untrusted idToken; trust only after ES256 JWKS verify + iss/aud/exp |
| bearer token → protected routes | requireRole gates access by verified session role |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-16 | Spoofing | forged/tampered LINE idToken | mitigate | jose ES256 remote-JWKS verify + iss/aud/exp checks (Pitfall 5); garbage-token test |
| T-00-17 | Spoofing | weak/plaintext password storage | mitigate | `Bun.password` Argon2id, self-encoded params; verify is constant-time (V2) |
| T-00-18 | Tampering | forged/altered session JWT | mitigate | jose HS256 sign/verify with `JWT_SECRET` (≥32B from env); tampered-token test; 2h exp (V3) |
| T-00-19 | Elevation of Privilege | role bypass on protected endpoints | mitigate | `requireRole` guard rejects missing/invalid session (401) and unpermitted role (403) (V4) |
| T-00-20 | Spoofing | credential stuffing on staff login | accept | Argon2id slows offline attack; per-endpoint rate limiting deferred to Phase 1 login UI (noted) |
</threat_model>
