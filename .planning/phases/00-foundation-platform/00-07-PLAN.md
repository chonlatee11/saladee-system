## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → prod API | Live HTTPS surface; only /health is unauthenticated; /webhook gated by HMAC |
| operator → dashboards | Human provisions secrets; must not paste secrets into the repo/logs |
| prod Neon / R2 / LINE → API | Real credentials; least-privilege tokens (R2 object R/W only) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-25 | Info Disclosure | secrets pasted into repo/CI logs during provisioning | mitigate | Secrets only in GitHub Actions Secrets + chmod-600 .env on VPS; verify `gh secret list` (names only); never echo values |
| T-00-26 | Spoofing | wrong LINE Login aud → idToken accepted from other channel | mitigate | Verify against the correct LINE_LOGIN_CHANNEL_ID; two-channel setup confirmed in Task 1 |
| T-00-27 | Info Disclosure | R2 bucket left public | mitigate | Task 1 acceptance requires a PRIVATE bucket; Task 2 verifies unsigned access is denied (Pitfall 4) |
| T-00-28 | Elevation of Privilege | over-broad R2 API token | mitigate | Create an Object Read/Write-scoped token only (not account admin) |
| T-00-SC2 | Tampering | prod migrate applies unreviewed schema | accept | Migrations are committed + reviewed in git; deploy gates on bun test; reversible down exists (00-02) |
</threat_model>
