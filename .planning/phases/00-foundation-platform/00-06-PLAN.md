<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet → Caddy :443 | TLS terminates at Caddy; only Caddy reaches Bun on localhost |
| GitHub Actions → VPS | SSH key-based deploy; secrets injected, never committed |
| CI secrets → runtime | Secrets flow GH Secrets → EnvironmentFile (600), never into the repo |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-21 | Tampering / Info Disclosure | TLS downgrade / MITM | mitigate | Caddy auto-HTTPS + HSTS header; Bun binds localhost only (no plaintext exposure) |
| T-00-22 | Info Disclosure | secrets committed via workflow/unit | mitigate | Secrets only via GH Secrets + EnvironmentFile (mode 600); source asserts no literals in unit/workflows |
| T-00-23 | Elevation of Privilege | compromised CI deploys arbitrary code | mitigate | Path-filtered workflows on main, bun test gate before deploy, key-scoped SSH; hosted runner (D-04, no runner on prod box) |
| T-00-24 | Availability | bad migration on deploy breaks prod | mitigate | db:migrate runs after code pull, before restart; reversible down SQL exists (00-02); test gate precedes deploy |
</threat_model>
