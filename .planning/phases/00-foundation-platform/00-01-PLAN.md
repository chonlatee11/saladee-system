<objective>
Stand up the monorepo skeleton and the thinnest bootable API slice: a Bun-workspaces repo (`api/` + `web/`), boot-time TypeBox env validation that fails fast, a structured JSON logger, and a composed Elysia app that serves `GET /health` (200 liveness) and exports its `type App` for Eden Treaty. All external clients (db, storage, line, auth) and their routes are created as **thin stub modules** so downstream wave-2 plans fill them in **without ever editing `index.ts`** — this is what lets waves 2 run in parallel with disjoint file ownership.

Purpose: Establish the platform every later slice attaches to (Criterion 1: HTTPS-ready, env-driven, no hardcoded secrets), and lock the module boundaries (interface-first) so DB, storage, LINE, and auth slices are independent.
Output: A repo that `bun install`s cleanly and boots to a passing `/health`, with env validation and Eden Treaty type-sharing proven.
</objective>
