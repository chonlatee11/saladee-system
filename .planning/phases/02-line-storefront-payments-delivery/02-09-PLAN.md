<threat_model>
## Trust Boundaries
| Boundary | Description |
|----------|-------------|
| member → /me/orders | Session-scoped read; must not leak other customers' orders. |
| reorder → prices | Re-pricing must use server rules, never the old snapshot as authority. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-33 | Information Disclosure | reading another customer's order history (IDOR) | high | mitigate | Every /me/orders query is scoped by the session's customerId; GET /me/orders/:id 404s if not theirs. |
| T-02-34 | Elevation of Privilege | guest accessing member-only history/reorder | medium | mitigate | Member guard rejects sessions without line_user_id (D-19). |
| T-02-35 | Tampering | reorder charging the old (stale) price | high | mitigate | Reorder re-prices at the current open round (dated-today-wins), flags unavailable items; never replays the snapshot price (D-20). |
</threat_model>
