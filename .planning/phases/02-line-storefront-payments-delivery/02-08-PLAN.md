## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-30 | Tampering | client showing a fee/total it computed to under-pay | high | mitigate | Wizard displays only server values from /delivery/quote + POST /orders; server is authoritative (defense reinforced client-side, enforced server-side in 02-03/02-04). |
| T-02-31 | Tampering | bypassing the usage-consent gate | medium | mitigate | CTA disabled client-side; server also rejects usage=false 422 (02-04). |
| T-02-32 | Tampering | re-fetching QR to reset the hold timer | medium | mitigate | GET /orders/:id/qr is idempotent server-side (02-04, singletonKey); UI only reads. |
