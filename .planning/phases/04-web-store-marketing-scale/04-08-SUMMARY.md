# Phase 04 Plan 08: Public Web Storefront (browse + SEO) Summary

Stood up `web-store/` — a NEW Nuxt SSR app (D-01) that reuses the EXISTING API (Eden Treaty), the shared `@theme` design tokens, and the LINE round model (D-04) — delivering the **browse half of ORD-05**: an SSR catalog and SSR product pages with SEO (sitemap + OG meta + product JSON-LD), edge-cached on Cloudflare Pages. Cart→checkout→pay is Plan 09.

- **Task 1 — Scaffold + tokens + Eden client** (`feat(04-08): scaffold …`, `9845413`)
  - New `web-store/` package: `nuxt@4.4.8`, `@nuxtjs/seo@5.3.2`, `@elysiajs/eden`, `tailwindcss@4.3.1` + `@tailwindcss/vite`.
  - `nuxt.config.ts`: `@nuxtjs/seo` module, `nitro.preset: cloudflare-pages` (host RESOLVED D-29/D-30), `routeRules` SWR edge cache (`/` + `/p/**`, 600s), `runtimeConfig.public.apiUrl` (`NUXT_PUBLIC_API_URL`), og-image generator disabled.
  - `assets/style.css`: `@import "tailwindcss"` + the `@theme` block **copied verbatim** from `web/src/style.css` + `store-max` 1200px layout constant.
  - `composables/useApi.ts`: `treaty<App>()` binding the store to the api contract (App type imported from `../../api/src/index`, erased at build).
  - `components/`: `EmptyState` + `QtyStepper` copied verbatim; `StoreVarietyCard` mirrors `web/` `VarietyCard` (NuxtLink → `/p/[id]`, store copy `ใส่ตะกร้า`). No shadcn, no Pinia.

- **Task 2 — SSR catalog + product page + SEO** (`feat(04-08): SSR catalog …`, `e41c689`)
  - `pages/index.vue`: SSR-fetches `GET /catalog` via `useAsyncData` (crawlable HTML); desktop hero (Display 28px, CTA `เลือกผักรอบนี้`) + multi-column grid (`store-max`, degrades mobile-first) reusing `StoreVarietyCard`; `ยังไม่เปิดรอบขาย` empty state when no round is open (same round model as LINE). `useSeoMeta` for OG/meta.
  - `pages/p/[id].vue`: SSR product page + gallery (cover + images, D-27/28); `useSeoMeta` OG (real product imagery) + `useSchemaOrg`/`defineProduct` product JSON-LD (D-06); real 404 on an unknown / closed-round id.
  - Sitemap auto-generated by `@nuxtjs/seo`; schema-org chunks emitted in the build output.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] nuxt-og-image required a missing renderer dependency at build**
- **Found during:** Task 2 build (`bun run build`).
- **Issue:** `@nuxtjs/seo` bundles `nuxt-og-image`, which fails the build unless a generated-OG renderer (`@takumi-rs/wasm`) is installed — even though this plan uses OG **meta tags with the product's real photo**, not generated OG images.
- **Fix:** `ogImage: { enabled: false }` in `nuxt.config.ts`. Avoids pulling a new native/wasm dep (which would itself need a legitimacy check) and keeps the install surface minimal (NFR-08). D-06 remains covered: sitemap + product JSON-LD + OG **meta** all still emit.
- **Files modified:** `web-store/nuxt.config.ts`.
- **Commit:** `9845413`.

**2. [Design interpretation] Components mirrored, not cross-package imported**
- The plan says "reuse `web/` components". `web/` `VarietyCard` imports `vue-router` and the LIFF cart store, which do not resolve in the Nuxt SSR build. Components were therefore **mirrored** into `web-store/components/` with tokens/markup verbatim (NuxtLink for routing). The binding inheritance rule — the verbatim `@theme` token block + no shadcn — is honored exactly.

## Known Stubs

Intentional; resolved by later plans / deferred prereqs (documented, not blocking the browse goal):

- **Add-to-cart is intent-only.** `StoreVarietyCard` emits `add`; `index.vue`/`p/[id].vue` handlers are no-ops. **Plan 09** wires cart → checkout → pay. This plan is the browse half of ORD-05 by design.
- **`site.url` placeholder** (`store.saladee.example`) in `nuxt.config.ts`. Real production domain is a deferred prereq (D-06 / user_setup `production-domain`), injected at deploy via `NUXT_PUBLIC_SITE_URL`. Sitemap/canonical absolute URLs finalize once the domain is live.
