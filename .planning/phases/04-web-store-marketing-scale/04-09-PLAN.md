<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| public browser → POST /orders | Guest checkout is unauthenticated; reservation + pricing + discount are server-authoritative. |
| client → discount | Client sends only couponCode + redeemPoints; server resolves the money. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-28 | Tampering | second reservation path via web store | high | mitigate | Web checkout calls the SAME POST /orders (guest path); no re-implemented reservation (D-02/NFR-02) |
| T-04-29 | Tampering | client-sent price/discount from the store | high | mitigate | Cart stores only line identifiers; client sends couponCode + integer redeemPoints; server resolves (mirrors T-02-17) |
| T-04-30 | DoS | public POST /orders abuse (stock exhaustion) | medium | mitigate | Existing holdExpiresAt sweep + MAX_SLIP_ATTEMPTS already mitigate; coupon adds only the guarded-limit write |
| T-04-31 | Spoofing | guest earning/redeeming points | medium | mitigate | Points member-only (line_user_id); guest sees the log-in hint (Pitfall 5) |
</threat_model>
